Rectangular 2px-radius button; labels are sentence-case verbs ("Request access", "Open terminal").

```jsx
<Button variant="primary" size="md">Request access</Button>
<Button variant="secondary">Read the docs</Button>
```

Variants: primary (blue fill), secondary (bordered), ghost (bare), danger (red, destructive/close-position). Sizes: sm for terminal toolbars, lg for marketing CTAs. Never pill-shaped, never uppercase.
